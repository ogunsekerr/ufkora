# T59 · Oyun ve alt oyun yayılım kuyruğu

T02 kaynak envanterinden türetildi. 50 bağımsız çalışma akışının üç pilotu dışındaki 47 akış için 282 açık alt görev. Bunlar Git deposundaki görev kartlarıdır; GitHub Issues oluşturulmadı. Oyunlar tamamlanmış sayılmaz. T02 statik envanterinin güncelliği ilk alt görevde tekrar doğrulanır.

Açı Ustası Balon Avı kartında all/inner/outer/calculate/multi; Olasılıkta coin/dice yanında birleşik both; Birim Küpte bütün görünümler aynı kartın kabul kapsamıdır. Bankanın 13×2 modu ayrı karttır; iç kontrol deep-link gibi gösterilmez. Toplama kazanım kodu uydurulmaz. Pilotlar P06-main/P07-isik/P07-kargo mevcut kabul raporlarında izlenir.
